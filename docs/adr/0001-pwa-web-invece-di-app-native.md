# PWA web invece di applicazioni native

CardScanner sarà una PWA eseguibile direttamente nel browser, anziché un'applicazione nativa Android/iOS o un'app Angular distribuita tramite Capacitor. Rinunciamo così all'accesso diretto a SDK esclusivamente nativi come Google ML Kit, ma evitiamo la complessità, i costi e i vincoli di pubblicazione degli store, in particolare dell'App Store Apple; il riconoscimento dovrà quindi usare tecnologie compatibili con il browser o servizi remoti.
